# Product Scope & Phase Boundaries — Timy

This directory defines the operational boundaries of the Timy project to prevent scope creep.

## Documents:
- **[mvp-scope.md](file:///c:/Users/rickm/OneDrive/Desktop/timy/docs/scope/mvp-scope.md)**: Explicit breakdown of MVP (Minimum Viable Product), Phase 2 enhancements, and Out-of-Scope future ideas.

## Scope Governance Rules:
1. **MVP is Sacred**: No Phase 2 or speculative features may be built before all MVP acceptance criteria are tested and verified.
2. **Explicit Proposal Constraints**: In accordance with Section 7 of the Project Proposal:
   > *"Timy will not cover other university systems such as course registration, examination management, or financial records."*
3. **Change Control**: Adding any new capability to the MVP requires technical lead consensus and an update to `docs/scope/mvp-scope.md`.
