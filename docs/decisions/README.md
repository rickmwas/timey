## Format of a TDR:
Each TDR should follow:
1. **Title & Status**: (Proposed, Accepted, Deprecated, Superseded)
2. **Context & Problem Statement**: The exact technical or product challenge.
3. **Considered Options**: The alternative solutions evaluated.
4. **Decision Outcome**: The chosen option and why.
5. **Pros and Cons of the Chosen Option**: Honest analysis of tradeoffs.
6. **Implementation Consequences**: What team members must adhere to.
